# Format: one domain per line; blank lines and lines starting with '#' are ignored. Entries are
# normalised exactly like submitted addresses (trimmed, lower-cased, trailing dot removed, IDN
# converted to punycode) and match the exact domain AND any of its subdomains, so do not list
# subdomains separately. Every entry is validated at API startup (ValidateOnStart) — a malformed
# entry, or an empty/missing list, stops the API from starting rather than silently allowing
# every address.
#
# Operators can add further domains without a code change via configuration:
#   Identity:AccountEmailDomainPolicy:AdditionalBlockedDomains
#
# Do NOT add domains here just because a provider also hosts organisation mail (Google Workspace,
# Microsoft 365, Zoho Workplace, ...): an organisation's own domain (person@company.co.uk) stays
# valid regardless of who hosts its mailboxes. Only the provider's consumer domains belong here.
