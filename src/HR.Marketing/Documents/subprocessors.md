# Subprocessors

| Provider | Purpose | Primary processing location |
|----------|---------|-----------------------------|
| Supabase | Authentication, PostgreSQL database and private file storage | London, United Kingdom (`eu-west-2`) |
| Railway | Application hosting and infrastructure | Amsterdam, Netherlands (EU West Metal) |
| Stripe | Subscription billing, payment processing and fraud prevention | United Kingdom, EEA and other locations described by Stripe |
| Postmark (AC PM LLC) | Account and transactional email delivery; message content is retained by Postmark for up to 45 days | United States and other locations used by Postmark and its infrastructure providers |
| Amazon Web Services (AWS) | Encrypted disaster-recovery backups of private files | London, United Kingdom (`eu-west-2`) |

AWS backup processing will begin before live Customer files are stored. We will update this page
if a provider, purpose or relevant location changes and will give Customers notice in accordance
with our [Data Processing Agreement](/data-processing-agreement).
